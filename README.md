# Word to PDF Converter Utility

Sebuah aplikasi utilitas Python sederhana untuk mengonversi dokumen Microsoft Word (.docx) menjadi format PDF dengan cepat. Sangat berguna untuk otomatisasi pengolahan dokumen kantor.

## Fitur
* Konversi file tunggal Word ke PDF.
* Menggunakan library `docx2pdf` yang handal.

## Cara Menjalankan
1. Instal dependensi:
   `pip install docx2pdf`
2. Siapkan file Word Anda (misal `dokumen_contoh.docx`).
3. Jalankan skrip:
   `python main.py`
